## 结论与待决定事项

1. **先引入这两份 Apache 改写稿，再加 P1。** 试做实现不需要新工具；P1 优先补源帧、有限区间审片、转写/词级检索与剪口播候选，之后补字幕与活动项目发现。按短视频真实素材做完成/降级验证，不直接启用所有宿主副本。全部能力迁移估算新增 40 个，后面 33 个不应作为首发前提。
2. **需要拍板：** 首批是否只选验收＋多素材竖版，并将转写/审片列为下一批；是否接受不引入云安装、付费生成、数字人及声音克隆；是否要项目级或经用户同意的全局分发。建议前两份先保留试做状态，实测后再放入正式目录。
3. **正式分发前由主 Agent 决定归属和第三方声明。** 建议一直优先取明确的 Apache 文件；如果某个只需要历史版的能力，逐文件核原始版权、来源和许可证，不能用当前许可替代未验证的旧包或素材权利。
